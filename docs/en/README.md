This directory holds the English documentation; the Simplified Chinese version is in `docs/zh-CN/`, with matching file names. The pages keep API identifiers, commands, protocol values, and real terminal output as they are. A code block without a complete `main()` is a usage snippet: it must run after drogon has initialized the plugin, for example in a beginning advice or a request handler.
